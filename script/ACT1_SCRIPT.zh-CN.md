# 第一幕 — 游戏对白导出

本阅读稿导出自历史 RPG Maker MV 工程的 `game/data/Map001.json`、`Map002.json` 和 `Map003.json`。事件按地图顺序排列，事件页可能受开关控制。对应地图数据记录该历史版本的实现。

本稿记录历史 RPG Maker MV 版本。已发布的 v10 采用 Unity，当前第一幕对白在 `Act1Game.cs` 和 `Act1Story.cs` 中，入口见 [Unity 工程](../RememberMeUnity/README.zh-CN.md)。修改阅读稿不会改变游戏。
