# 交互约定

第一幕与第二幕共用 StoryInput 和 Act1HUD。后续修改交互时先阅读本文件。

| 当前状态 | 键盘 | 鼠标 | 退出方式 |
| --- | --- | --- | --- |
| 自由探索 | WASD 移动，E、Enter、小键盘 Enter、Space 触发屏幕底部提示 | 点击底部交互提示，触发同一个目标 | Esc 暂停，I 打开物品栏 |
| 对话 | E、Enter、小键盘 Enter、Space 继续 | 点击对话框继续 | 读完当前对话 |
| 选择或暂停菜单 | WASD 或方向键选项，E、Enter、小键盘 Enter、Space 确认 | 悬停选中，点击确认 | Esc 关闭菜单 |
| 配方卡排序 | 同菜单，Backspace 撤回最后一张 | 选择“Undo last card”，或点击已放卡片撤回该位置及后续卡片 | Esc 暂时关闭，保留未完成顺序 |
| 搅拌 | E、Enter、小键盘 Enter、Space 搅拌一次 | 点击 Stir | Esc 关闭，保留次数 |
| 放面团 | E、Enter、小键盘 Enter、Space 放入下一个可用槽位 | 拖面团到槽位或点击槽位 | Esc 关闭，保留进度 |

## 输入和显示

- 每帧只消费一次确认输入，由 StoryInput.Consume 处理。菜单通过 Act1HUD.HandleMenuInput 提交。
- EventSystem.sendNavigationEvents 关闭。方向键和确认由上述菜单方法处理，鼠标仍通过 EventSystem 工作，避免同一次 Enter 在两个入口重复提交。
- 菜单的 Choose 会先 CloseChoices 再执行回调。回调内的撤回判断应使用章节与已放卡片，避免依赖刚被清除的 sortingCards。
- 剧情自动行走使用 GraceMotor.MoveScripted，保留步态并通过同一碰撞检测。Place 用于切换场景或恢复存档。动画最终由 GraceMotor.LateUpdate 更新，避免被站姿覆盖。
- 世界交互都走当前 nearby 目标的原有 Use/Trigger 方法。鼠标点击提示也走该入口，受同样的距离、碰撞、剧情条件约束。
- 对话框的点击交给 Act1HUD.TakeContinue，不能同时轮询全屏鼠标点击，否则点击菜单会误跳过下一句。
- 新增剧情图、遮罩和可点击界面使用现有 Canvas。全屏 OnGUI 遮罩会盖住 Canvas 对话框，水门曾因此呈现黑屏。
- 所有收集物由故事状态决定是否进入物品栏。展示图片复用实际美术资源，拿到后不再把物品悬浮绑定到角色。

## 位置和流程

- 墓园和第一幕室内坐标使用 96 PPU，原点在画面左下。厨房等第二幕使用 134 PPU，逻辑坐标原点在左上，必须经 World 转换。
- 第一次父亲闪回和八音盒空屋是两个房间。修改壁炉后必须分别测试正面和侧面接近。旧存档落入新碰撞体时，Enter 会将 Grace 恢复到可行走地面。
- 厨房门槛交互始终存在。烘焙完成前说明留下的原因，拿托盘后推进循环剧情。提示位置由 doorwayPassage 和角色脚部半径计算，厨房与走廊入口使用同样的规则。
- 三张配方卡在对应柜面及冰箱处实际显示。任意顺序收集，收集后隐藏原位置卡片，保留物品栏原画和进度，重复查看不增加数量。
- 暂停菜单包含继续、物品栏、保存、读取及返回标题。第一幕和第二幕各自保存进度。厨房测试使用独立 QA 存档键，避免改写玩家记录。

## 回归验证

运行 Act1Builder.Build 后，用 Windows 成品参数 -remember-smoke -with-kitchen -kitchen-capture 加截图目录验证。检查首次闪回碰撞、空屋碰撞、暂停物品栏、厨房存读档、任意顺序及重复收卡、错误配方重试、搅拌关闭后继续、拖放、门槛提示、水门对话可见并可点击返回、奶奶跟随和结尾。
