# Remember Me · Unity 第一幕

英文 Windows 试玩版包含第一幕葬礼和第二幕第一场。Grace 在墓园发现爸爸在哭，随后回想起爸爸和奶奶在门边的争执。妈妈交给 Grace 遗物。八音盒勾起奶奶空屋的短暂回忆，随后用雨中回家的插画和第二幕幕卡接到 Grace 的卧室。这个仓库中的 RPG Maker MV 版存放在根目录的 `game/`。

## 试玩和编辑

- 构建 Windows 版后，在 `RememberMeUnity/Build/Windows/` 双击 `RememberMe.exe`。转移试玩版时请复制整个 `Windows` 文件夹。也可直接打开 [Unity 网页试玩版](https://jeddakholmes-byte.github.io/RememberGame/unity/)。
- WASD 或方向键可轻点转身，按住移动。贴着障碍时也会朝向按下的方向。Shift 跑步并解除蹲下，C 切换蹲下，E 或 Enter 互动，I 打开物品栏，Esc 暂停。暂停菜单可保存和读取，标题页的 Continue 可继续已保存的游戏。对白与界面文字使用 Windows 的 Times New Roman。
- 横排选项使用左右键，竖排菜单使用上下键，也可用鼠标。当前选项会显示金色底、加粗文字和箭头。第一幕插图逐渐淡出，露出已加载的墓园后再显示开场对白。
- 用 Unity Hub 打开 `RememberMeUnity/`，编辑器版本为 `6000.6.1f1`。主场景是 `Assets/Scenes/RememberMeAct1.unity`。工程用 2D URP 模板创建，默认 2D 编辑模式、正交相机和 2D 碰撞。
- 第一幕主线可直接完成。沿主路找奶奶的白花和墓碑，靠近时墓碑有金色角标。白花、旧墓、登记册、亲属和便笺可自由调查。靠近路上的积水后，按 C 蹲下，再按 E 或 Enter 查看倒影插画。还没读奶奶的墓碑时，回到大门会收到妈妈的指引。调查完四座特色墓碑后，镜头短暂转到妈妈，再回到 Grace。

## 美术规格

- 同一房间的物件遵循偏俯的正面视角。桌沿保持水平，书、茶杯、篮子和信件为独立图层，以桌面做放置基准。开门和关门共用门槛位置，外沿需要保持透明干净。世界坐标采用 96 PPU，角色以脚底为锚点。
- 保留爸妈、奶奶和爷爷的常态四向图，重制了姑姑与 James 舅舅的低清四向图。读完奶奶墓碑后，爸爸换成用纸巾擦眼泪的四向姿态，原 MV 的对白立绘随说话人出现。Grace 的站立、走路、跑步和蹲姿出自同一张动作表，按家人素材匹配视角与轮廓。每个方向都以站姿为裁切与比例基准。
- 墓园里的角色是 Grace 和她的五位家人。原来的悼念者素材保存在 `Assets/Art/Actors` 中，巡逻逻辑保存在 `Act1Patrol.cs`。
- 墓园为 22 × 15 世界单位，有六排共 48 个墓位。枯花、苔藓、尖顶石碑和三粒石子各对应一座可调查的旧墓，普通墓位使用素面石碑。3,168 × 2,160 的细草地、石铺路、围栏、墓碑和人物分别渲染。沿用原标题和封箱插图，幕卡使用原剧本的章节名。拆箱全览、开钥匙、雨夜窗景和回家路上的过场分别显示。

## 课程目标与剧情依据

对照《RememberMeScript》、11 月 18 日两份会议记录、CSS5190 第 2、3 课与项目报告指南。第一幕保留孩子的视角，呈现爸爸承担照护压力时的挫败，以及失去家人后的悲伤。第二幕从卧室里遗物箱的一声轻响开始，Grace 再次开盒，并在厨房里第一次与记忆中的奶奶重逢。当前验收覆盖设计和技术行为，课程要求的玩家同理心或学习效果需要另做玩家评估。

互动提示借鉴靠近对象时给出明确操作的做法。Grace 从人物或物件的实际边缘获得提示，相邻目标会结合朝向排序。移动借鉴二维动作中清楚可辨的剪影，走跑切换延续同一步相。 [《元气骑士》官方玩法说明](https://soulknight.chillyroom.com/et/article/base/67) · [《空洞骑士》官方介绍](https://www.hollowknight.com/)
